Introducción a HTML

3 de octubre de 2026

HTML es el lenguaje que define la estructura de una página web. Sus elementos indican qué contenido es un título, un párrafo, un enlace o una sección.

La estructura de un documento

Una página HTML comienza con una declaración de tipo de documento. Dentro de <html>, el elemento <head> contiene información sobre la página y <body> contiene lo que se muestra en pantalla.

Elementos semánticos

Elementos como <header>, <main>, <article> y <footer> describen la función de cada parte. Esto ayuda a las personas que usan lectores de pantalla y facilita entender el documento.

Enlaces

Con <a href="..."> se conecta una página con otra. El texto del enlace debe explicar con claridad adónde lleva.
